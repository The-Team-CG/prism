## Design Context

### Users
Event coordinators, venue managers, and hospitality professionals setting up floor plans for events — conferences, weddings, galas, corporate dinners. Used primarily on desktop in a venue operations or back-office context. Medium technical fluency; expect a professional tool, not a consumer app.

### Brand Personality
Precise · Energetic · Hospitality-warm

The interface should feel like a serious professional tool that also has personality. Not cold like CAD software, not playful like a consumer app — something between Figma's precision and the warmth of a great hospitality experience.

### Aesthetic Direction
Dark mode tool UI — Figma-like in structure and density. Canvas takes maximum space, panels are minimal chrome. Three brand colors applied with restraint:
- Primary: #9B51E0 (purple) — primary actions, selections, interactive states
- Secondary: #FF219D (hot pink) — selected object handles, highlights, active indicators  
- Tertiary: #F79007 (amber) — warnings, blueprint overlay accents, status
- Neutral: #1F1F1F base → full dark palette derived from this

Near-black canvas (#0b0a10). Dark panels (#13111e). Tight, dense inspector panels like Figma's properties panel. Subtle borders. Small but crisp typography.

Anti-reference: NOT like AutoCAD or Revit (too cold/technical). NOT like Google Slides (too generic/consumer).

### Typography
Bricolage Grotesque — variable weight grotesque with warmth and personality. Single family for the whole app (this is a tool UI, not a content site). Sizes: 10px labels, 11px body, 12px values, 13px section headings.

### Design Principles
1. **Canvas first** — the drawing surface is the product, UI chrome should disappear
2. **Progressive disclosure** — show only what's relevant to the current selection
3. **Precision by default** — numbers, coordinates, and dimensions are always visible and editable
4. **Warmth through color** — the purple/pink/amber palette brings energy without sacrificing professionalism
5. **Density with breathing room** — tight spacing within sections, generous spacing between them
